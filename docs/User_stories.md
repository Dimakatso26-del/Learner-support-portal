# User Stories

1. As a learner, I want to register and sign in so that I can manage my own tasks.  
   - Acceptance criteria: Registration form validates input; successful sign-in shows dashboard.

2. As a learner, I want to create, edit, and delete tasks so that I can track my learning progress.  
   - Acceptance criteria: CRUD operations work with Firebase; confirmation before deletion.

3. As a learner, I want to book support sessions so that I can get help when needed.  
   - Acceptance criteria: Booking form validates input; confirmation message shown.

4. As a learner, I want to view a progress summary so that I can see completed vs outstanding work.  
   - Acceptance criteria: Dashboard calculates totals and displays dynamically.

5. As a learner, I want to set preferences (e.g., theme) so that the portal feels personalized.  
   - Acceptance criteria: Preference stored in a cookie; applied on reload.

6. As a learner, I want to play a mini-game so that I can reinforce programming concepts.  
   - Acceptance criteria: Game loads, records score, and saves results in Firebase.
