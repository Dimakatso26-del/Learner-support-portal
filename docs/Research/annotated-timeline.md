# Annotated JavaScript Timeline

## 1995 – Creation
- Brendan Eich creates JavaScript in Netscape in just 10 days.
- Originally called *Mocha*, then *LiveScript*, finally renamed *JavaScript*.
- **Impact**: Introduced scripting for web interactivity, making websites dynamic instead of static.

## 2009 – ES5
- ECMAScript 5 standardized features across browsers.
- Added **strict mode**, **JSON support**, and new **array methods**.
- **Impact**: Improved reliability and consistency, making JavaScript safer to use in larger projects.

## 2015 – ES6 / ES2015
- Major turning point in JavaScript’s evolution.
- Introduced `let` and `const`, arrow functions, classes, template literals, promises, and modules.
- **Impact**: Transformed JavaScript into a full application language, suitable for both client and server development.

## 2017 onward – Annual releases
- ECMAScript moved to yearly updates.
- Features like **async/await**, **optional chaining**, and other incremental improvements.
- **Impact**: Continuous evolution keeps JavaScript modern and competitive.

# Annotated Timeline of JavaScript

## 1995 Creation

Netscape's Brendan Eich was the **creation developer** of JavaScript Programming Language. Mocha → LiveScript → JavaScript was the **original name.**

- The **goal** is to provide dynamic, interactive webpages in Netscape Navigator.
- **Impact:** Alongside HTML and CSS, it quickly became a fundamental web technology.

## 1997: Standardisation of ECMAScript

To standardise JavaScript across browsers, **ECMA International** released the first ECMAScript specification.

- The foundational language rules were established in **ES1 (1997)**.
- Regular expressions, try/catch exception handling, and new string methods were added in **ES3 (1999)**.

## ES5 in 2009

- **Important characteristics:**
With regards to safer coding, it uses strict mode.
support for JSON (standardised data exchange).
object property getters and setters.
- **Impact:** JavaScript is now more dependable and safe due to its widespread adoption by contemporary browsers.

## ES6/ES2015 in 2015

**Significant update:** regarded as the beginning of "modern JavaScript"

- **Important characteristics:**
Structured programming classes and modules.
For succinct syntax, use arrow functions.
Asynchronous programming promises.
To make managing strings easier, use template literals.

- **Impact:** Enabled large-scale applications and frameworks like React, Angular, and Vue, revolutionising JavaScript development

## Annual Releases from 2016 to the present

For better asynchronous programming, **ES2017** introduced async/await.

- **ES2018–2020:** nullish coalescing, optional chaining, and spread/rest operators.
- **Ongoing:** With constant updates from the TC39 group, JavaScript is now a live standard.

### Observations
- **Characteristic 1**: JavaScript is dynamically typed — values can change type at runtime.
- **Characteristic 2**: It is interpreted/JIT‑compiled, running directly in the browser without a separate compile step.
- **Characteristic 3**: It interacts with the DOM and responds to user events.
- **Limitation**: Temporal dead zone with `let` variables causes runtime errors if accessed before declaration.
